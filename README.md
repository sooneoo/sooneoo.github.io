# Sooneoo public website

Static public website for Sooneoo, deployed through GitHub Pages.

## Structure

- `index.html` — public site content
- `styles.css` — responsive layout and visual system
- `.nojekyll` — serves the repository as plain static files

No framework, package manager, build step, or JavaScript is required.

## Publishing policy

Technical statements about individual Sooneoo projects must be checked against their current source documentation before publication. Planned or experimental capabilities must not be presented as implemented.
