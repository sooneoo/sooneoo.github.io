01 / active development

Soo

Current documented version: 1.17.0

Soo is a statically analyzed functional/declarative programming language built around a graph execution model.

sourcefrontendSoo_GraphDFRM

Current implementation

libsoo provides the frontend and a target-independent middle-end. DFRM is the current reference interpreter/backend for evaluating verified Soo graphs.

Development stage

The language, runtime, standard library, and reference backend are under active development. The current implementation is a working research system rather than a finished production platform.

Scope boundary

Native acceleration, accelerator providers, and multi-device execution exist in future design work, not as capabilities of the current DFRM backend.

Public technical claims on this site are intentionally limited to behavior documented and verified in the current project sources.

About / Mission

Make ambitious technical ideas concrete enough to test.

Sooneoo exists to pursue technical and research projects without forcing them into a short-term product narrative. The goal is to build understandable systems, measure what actually works, and publish results when the evidence is strong enough.

We prefer precise documentation, reproducible demonstrations, and explicit limitations over broad claims. Research direction comes first; communication follows the technology.
